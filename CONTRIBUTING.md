# Panduan Kontribusi (CONTRIBUTING)

## Pendahuluan

Repository ini dibuat sebagai bagian dari pembelajaran mata kuliah Rekayasa Perangkat Lunak. Panduan kontribusi disusun untuk membiasakan penerapan alur kerja yang terstruktur, menjaga kualitas dokumentasi, serta memudahkan pengelolaan perubahan dalam sebuah proyek.

Meskipun repository ini digunakan untuk tugas individu, aturan berikut dibuat sebagai latihan apabila nantinya terlibat dalam pengembangan perangkat lunak bersama tim.

## 1. Aturan Pembuatan Branch

Setiap perubahan atau penambahan fitur sebaiknya dilakukan melalui branch terpisah agar tidak langsung memengaruhi branch utama (`main`).

Penamaan branch harus singkat dan menggambarkan pekerjaan yang dilakukan.

Contoh:

- `docs/update-readme` : Memperbarui dokumentasi README.
- `docs/add-report` : Menambahkan laporan tugas.
- `fix/correct-information` : Memperbaiki informasi yang kurang tepat.

## 2. Format Penulisan Commit

Setiap perubahan yang dilakukan harus memiliki pesan commit yang jelas agar riwayat pengerjaan mudah dipahami.

Format yang digunakan:

`tipe: deskripsi perubahan`

Contoh:

- `docs: add README`
- `docs: add work commitments`
- `docs: update Google Maps analysis`
- `fix: correct report information`

Pesan commit sebaiknya menggambarkan perubahan yang benar-benar dilakukan dan tidak menggunakan keterangan yang terlalu umum, seperti "update" atau "revisi" tanpa penjelasan.

## 3. Proses Pull Request

Sebelum perubahan digabungkan ke branch utama, kontributor perlu mengikuti langkah berikut:

1. Membuat branch sesuai pekerjaan yang akan dilakukan.
2. Melakukan perubahan atau penambahan file.
3. Memeriksa kembali hasil pekerjaan.
4. Melakukan commit dengan pesan yang jelas.
5. Mengajukan pull request ke branch utama (`main`).
6. Menuliskan ringkasan perubahan yang telah dilakukan.
7. Melakukan perbaikan apabila terdapat masukan dari proses review.

Perubahan dapat digabungkan setelah dinyatakan sesuai dengan kebutuhan proyek.

## 4. Aturan Review

Setiap perubahan perlu diperiksa untuk memastikan bahwa:

- Isi dokumen sesuai dengan tujuan pengerjaan.
- Tidak terdapat informasi yang keliru atau tidak memiliki dasar.
- Penulisan dan format dokumentasi mudah dipahami.
- Tidak terdapat data pribadi atau informasi rahasia yang dibagikan.
- Perubahan tidak menghilangkan bagian penting dari pekerjaan sebelumnya.

## 5. Etika Kontribusi

Setiap kontributor diharapkan menjaga komunikasi yang sopan, menghargai pendapat orang lain, dan bertanggung jawab terhadap pekerjaan yang dilakukan.

Penggunaan referensi maupun bantuan AI harus dilakukan secara jujur dan tidak digunakan untuk membuat data atau hasil pengamatan yang tidak benar.

## Penutup

Panduan ini dibuat untuk membangun kebiasaan kerja yang teratur dan bertanggung jawab. Dengan mengikuti aturan kontribusi, setiap perubahan dalam repository diharapkan dapat terdokumentasi dengan baik serta mudah dipahami dan dievaluasi.
